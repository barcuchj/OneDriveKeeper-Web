# OneDrive Keeper public site

This folder is the complete, static public-site payload for GitHub Pages at
`https://barcuchj.github.io/OneDriveKeeper-Web/`. Copy its contents (including
`.nojekyll`) to the root of the separate public repository. Do not copy private
validation notes, app source, Git history, screenshots, or account data.

The site describes an independent macOS utility concept and private prototype
for monitoring whether OneDrive processes are running. Process availability
does not verify that files are synchronized. No download or release date is
available. The project is not affiliated with, endorsed by, or sponsored by
Microsoft or Apple.

Files: `README.md`, `index.html`, `favicon.svg`, `og-image.png`, `robots.txt`,
`sitemap.xml`, and `.nojekyll`. The canonical and social-preview URLs use the
project Pages URL above. Keep those paths and absolute URLs aligned if the
hosting URL changes.

The survey is not open and the page collects no responses. Do not replace its
status with a Google Forms link until the real responder URL has been tested
without signing in from a private browser window, including removal of the
test response. The form must remain voluntary and must not collect email
addresses. The private development repository documents the form setup and
verification requirements; those private materials must never be copied here.

No analytics, tracking cookies, scripts, remote assets, external embeds, app
source, or downloadable app are included. GitHub Pages may process ordinary
hosting request data under GitHub's privacy terms.
