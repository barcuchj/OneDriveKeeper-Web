Keep OneDrive running on your Mac.

If your OneDrive client stops unexpectedly, you should know. This small, native menu-bar utility monitors the client, notifies you and can automatically bring it back.

Help shape the free beta

Working private prototype · macOS 14+ target · No public download yet

A second pair of eyes for your sync client.

The current private prototype focuses on process availability. These capabilities are implemented in the prototype; wider compatibility testing is still needed.

01 / MONITOR

Continuous monitoring

Detects when a monitored OneDrive process is no longer running.

02 / RECOVER

Automatic recovery

Restarts missing clients with configurable limits to avoid repeated restart loops.

03 / NOTIFY

Native notifications

Receive macOS notifications about observed outages and recovery attempts, subject to system notification settings.

04 / REVIEW

Incident history

Review observed terminations, downtime estimates and recovery attempts by account.

05 / CONTROL

Account-level controls

Monitor a personal and a first work or school account, pause monitoring or request a graceful restart.

06 / PRIVACY

Local by design

The app stores its operational history locally. It does not collect file contents or account credentials, and has no built-in telemetry.

What it does — and what it does not.

A running client does not guarantee that files are synchronized. The difference matters.

Available in the private prototype

  • Detecting process termination and verifying relaunch.
  • Automatic and manual recovery with safety limits.
  • Local history, account filtering and launch at login.

Under consideration

  • Detecting stalled synchronization and file conflicts.
  • More account configurations and compatibility testing.
  • Version-specific diagnostics and detailed reliability statistics.

Sync health detection is not implemented. This is not a backup tool.

Frequently asked questions

Can I download it now?

Not yet. A working private prototype exists. This site is intended to assess interest before preparing a public beta. No release date is promised.

Does it verify that all files are synchronized?

No. The current prototype monitors OneDrive processes, not the success or completeness of file synchronization.

Which Macs and accounts are supported?

The current prototype targets macOS 14 and later. A personal account and a first work or school account have been tested on the developer's Apple Silicon Mac. Other versions, hardware and account configurations need wider testing.

Does it replace Microsoft OneDrive?

No. It is an independent utility intended to work alongside the existing Microsoft client.

Does the website track me?

This page includes no analytics scripts, cookies set by this page or third-party embeds. GitHub hosts the page and may process standard request data under its own privacy policies. A future external survey will have a separate privacy notice.
